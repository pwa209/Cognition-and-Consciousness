## BMVP readiness, not a transfer finding

The initial fixed report-MRI cohort consists of archives `191`, `223`, and
`238`, chosen by the existence of one task log/CSV and complete 720-trigger
task trains before examining neural effects. Their behavior/log checks found
4, 5, and 4 task runs respectively, each with 32 task trials and first onset
about ten seconds after the first scanner trigger. The four converted `191`
runs passed the independent DICOM/inter-run timing pilot. `223` and `238`
still require DICOM conversion, mapping, preprocessing and independent
calibration. This cohort is a technical pilot, not a selected scientific sample.

The no-report exemplar has 216 task-trial onsets across nine 700-trigger task
trains; one center-relevant onset is at 707.916 s after run start and cannot
be treated as in-scan. It remains a documented technical exception. Neither
an unrequested response nor this timing exception is an E=0 label.

The full E–K_content–R P08 is not estimable with BMVP because BMVP has no
K_content assay. A separately labeled exploratory E–R transfer would require
a verified BMVP neural bundle, fixed common feature/condition units and an
independent report-measurement bridge. Source-only calibration, not held-out
neural outcomes, must determine that bridge. There is no valid multi-family
P08 score at this checkpoint.
